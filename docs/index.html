Customer (Booking)

  1. Open the booking page.
  2. Choose Province, City, and Store.
  3. Choose your service(s).
  4. Choose date and time.
  5. Keep Best available consultant, or pick one.
  6. Enter your details and tick consent.
  7. Click Confirm booking.
  8. Save your booking code from the confirmation screen/email.

Customer (Manage Booking)

  1. Open booking page.
  2. Click Change / Manage a booking.
  3. Enter booking code and email.
  4. Choose Reschedule or Cancel.
  5. Confirm the action.

Consultant

  1. Go to Login.
  2. Enter your username and password.
  3. Open Consultant page.
  4. Use tabs:
  5. Today: today's queue
  6. Upcoming: future bookings
  7. Logs: activity history
  8. Update booking status in order:
  9. Confirmed -> Checked-in -> In service -> Completed
  10. Use quick actions if needed:
  11. Reassign request
  12. Reschedule
  13. Cancel / No-show
  14. Use Refresh after major updates.

Store Manager

  1. Log in as store manager.
  2. Open Ops/Bookings view.
  3. Filter by date, status, consultant.
  4. Monitor today's queue for your store.
  5. Reassign bookings if needed.
  6. Check no-show/cancel trends in view.
  7. Escalate cross-store issues to area manager.

Area Manager

  1. Log in as area manager.
  2. Open Ops filters.
  3. Select any pilot store (all 4 are in scope).
  4. Monitor Today, In Progress, Completed.
  5. Use filters for status/store/consultant/date.
  6. Reassign when consultants are unavailable.
  7. Track service flow and queue bottlenecks.

Executive (National Focus)

  1. Log in as exec.
  2. Open analytics/exec dashboards.
  3. Review:
  4. daily trends
  5. store summaries
  6. consultant summaries
  7. KPI snapshot
  8. Focus on:
  9. throughput
  10. no-show rate
  11. completion rate
  12. cancellations
  13. Use exports for reporting.

Exports (Exec)

  1. Log in as exec.
  2. Open export page.
  3. Set date range.
  4. Apply store/consultant filters if needed.
  5. Export bookings dataset.
  6. Share CSV with leadership/ops.

Troubleshooting (Demo)

  1. No slots: change date or service combination.
  2. Wrong login: use username + password, not display name.
  3. Missing booking: click Refresh.
  4. Cold start delay: wait, then retry once.
  5. Time checks: all booking times should display in RSA/SAST.
